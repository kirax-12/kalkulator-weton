# Kalkulator Weton

**Demo live:** [kalkulator-weton di GitHub Pages](https://kirax-12.github.io/kalkulator-weton/)

Web app statis buat mengecek weton Jawa dari tanggal lahir: hari + pasaran, neptu, watak menurut primbon, umur detail, total hari hidup, zodiak, dan hitung mundur ulang tahun berikutnya. Lengkap dengan weton hari ini di bagian atas halaman.

Dibuat oleh **Remike Dev**.

## Fitur

- **Weton akurat** — dihitung dari jangkar yang terverifikasi: 17 Agustus 1945 = Jumat Legi (hari Proklamasi), lalu siklus pasaran 5 hari (Legi, Pahing, Pon, Wage, Kliwon).
- **Neptu lengkap** — nilai hari (Minggu 5 … Sabtu 9) + nilai pasaran (Legi 5 … Kliwon 8) dan totalnya.
- **Watak pasaran** — ringkasan sifat menurut primbon, diberi label jelas sebagai hiburan/budaya.
- **Umur detail** — tahun, bulan, hari; total hari hidup; zodiak; ulang tahun berikutnya beserta sisa harinya.
- **Weton hari ini** — tampil otomatis di header setiap halaman dibuka.

## Cara Pakai

1. Isi nama (opsional) dan tanggal lahir.
2. Klik **Cek Weton Saya** — semua hasil muncul dalam satu kartu.

## Teknologi

HTML · CSS · JavaScript murni, tanpa framework dan tanpa build step. Semua hitungan tanggal memakai UTC agar tidak bergeser karena zona waktu.
